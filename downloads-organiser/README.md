# Downloads Folder Organiser

A simple Python automation tool that automatically organises files in your **Downloads** folder into folders based on their file type.

## Features

* Organises files into categories such as Documents, Images, Videos, Audio, Archives, and Code
* Automatically creates folders if they do not exist
* Prevents overwriting existing files
* Uses only Python's standard library

## Requirements

* Python 3

## Usage

Run the script:

```bash
python downloads_organiser.py
```

The program scans your Downloads folder and moves files into the appropriate folders automatically.
