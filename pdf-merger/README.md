PDF Merger

A simple Python script that merges all PDF files in the current directory into a single PDF document.

Features
Automatically detects all PDF files in the current folder
Merges PDFs in alphabetical order
Generates a single output file named combined.pdf
Lightweight and easy to use
Requirements
Python 3
PyPDF2

Install the required package:

pip install PyPDF2
Usage
Place the script in the folder containing the PDF files.
Run the script:
python pdf_merger.py
A new file named combined.pdf will be created in the same directory.
